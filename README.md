# AstroGlow: Orbital Sunset & Twilight Time Visualizer

## Purpose
**AstroGlow** is an interactive science demo and visualization tool designed to compute and simulate atmospheric scattering, twilight phases (civil, nautical, astronomical), and solar trajectories across different global coordinates and seasons.

## Features
- **Interactive Time Scrubber**: Scrub through a 24-hour UTC timeline to observe precise solar elevation changes, azimuth angles, and real-time canvas sky color shifts.
- **Preset & Custom Locations**: Choose from major global cities or input exact latitude and longitude coordinates.
- **Day of Year Control**: Simulate solstice, equinox, or any seasonal day of the year.
- **Dynamic Sky & Star Rendering**: Atmospheric Rayleigh scattering approximation rendering golden hours, twilight gradients, and starry night skies.
- **Automated Event Timeline**: Automatically calculates sunrise, sunset, and twilight windows for the selected day.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser.
3. No build tools, external servers, or network requests required.

*Note: This is a fully static client-side educational project.*
